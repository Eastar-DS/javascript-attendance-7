# 우테코 7기 프리코스 최종 테스트 - 출석부 (JavaScript)

> 이 문서는 **Node.js(JavaScript)** 로 콘솔에서 동작하는 “출석부” 프로그램을 구현하기 위한 요구사항을 정리한 README입니다.
> (원문 과제 README를 참고해 **JS 관점으로 재구성**했으며, 문장/구조는 `javascript-oncall-6` 스타일을 의도해 작성했습니다.)

---

## 📌 목표

12월 한 달 동안의 출석 기록을 관리하는 콘솔 프로그램을 구현한다.

- 사용자는 메뉴를 통해 기능을 선택한다.
- 출석 기록을 확인/수정/조회할 수 있다.
- 제적 위험자를 기준에 따라 분류 및 출력할 수 있다.

---

## ✅ 기능 요구사항

프로그램은 아래 메뉴를 제공한다.

1. **출석 확인**
2. **출석 수정**
3. **크루별 출석 기록 확인**
4. **제적 위험자 확인**
   Q. **종료**

프로그램은 사용자가 `Q`를 입력하기 전까지 반복 실행한다.
각 기능 수행이 끝나면 다시 초기 메뉴로 돌아간다.

---

## 🧭 동작 흐름

### 1) 초기 메뉴 출력

- “오늘 날짜”를 출력하고 메뉴를 보여준다.
- 사용자는 `1~4` 또는 `Q`를 입력한다.

### 2) 출석 확인

- 사용자에게 **닉네임**을 입력받는다.
- 사용자에게 **등교 시간(HH:MM)** 을 입력받는다.
- “오늘 날짜”에 대한 출석 기록을 저장한다.
- 처리 후 해당 사용자의 **출석/지각/결석 횟수**를 출력한다.
- 이미 오늘 출석한 경우 에러 처리한다.

### 3) 출석 수정

- 사용자에게 **닉네임**을 입력받는다.
- 사용자에게 **수정하려는 날짜(예: 12월 14일)** 를 입력받는다.
- 사용자에게 **등교 시간(HH:MM)** 을 입력받는다.
- 해당 날짜 기록을 변경하고 **변경 전/후 기록을 함께 출력**한다.
- 미래 날짜는 수정할 수 없다.

### 4) 크루별 출석 기록 확인

- 사용자에게 **닉네임**을 입력받는다.
- 해당 닉네임의 “12월 출석 기록”을 날짜별로 출력한다.
- 기록이 없는 등교일은 `--:-- (결석)`으로 간주한다.
- 출석/지각/결석 합계를 출력한다.
- 필요 시 “경고/면담/제적” 상태 문구를 함께 출력한다.

### 5) 제적 위험자 확인

- 모든 크루의 출석을 집계하여 제적 위험자를 출력한다.
- 출력 순서와 정렬 규칙은 아래 “제적 위험자 규칙”을 따른다.

---

## 🧩 도메인 규칙

### 📅 등교일 규칙

- **주말 및 공휴일에는 출석할 수 없다.**
- 등교일이 아닌 날에 출석 확인/수정을 시도하면 에러 처리한다.

### 🕗 운영 시간 규칙

- **캠퍼스 운영 시간:** `08:00 ~ 23:00`
- 운영 시간 외의 등교 시간 입력은 에러 처리한다.

### ⏰ 지각/결석 판정 기준

요일에 따라 “시작 시각”이 다르다.

- **월요일:** `13:00`
- **화~금:** `10:00`

판정 규칙:

- 시작 시각 기준 **5분 초과** → **지각**
- 시작 시각 기준 **30분 초과** → **결석**
- 그 외는 **출석**

> 예: 화요일 기준 시작 시각 10:00
>
> - 10:05까지 출석
> - 10:06 ~ 10:30 지각
> - 10:31부터 결석

---

## 🚨 제적 위험자 규칙

### 1) 결석 환산

- **지각 3회 = 결석 1회**로 환산한다.

### 2) 분류 기준

- **경고 대상자:** 결석 2회 이상
- **면담 대상자:** 결석 3회 이상
- **제적 대상자:** 결석 5회 초과

### 3) 출력 우선순위

- **제적 대상자 → 면담 대상자 → 경고 대상자** 순으로 출력한다.

### 4) 정렬 규칙

동일 그룹 내 정렬은 다음 순서로 정한다.

1. (지각 환산 반영 후) **결석 횟수 내림차순**
2. 결석이 같으면 **닉네임 오름차순**

## 💾 데이터 파일 요구사항 (CSV)

- 프로그램은 출석 기록을 파일에서 불러와 사용한다.
- 출석 기록 파일 이름은 `attendances.csv` (원문에 오타 표기가 있을 수 있으나, 구현에서는 실제 파일명을 기준으로 한다).
- 프로그램은 파일 내용을 읽어 “12월 출석 기록”을 구성한다.

> ⚠️ CSV의 정확한 컬럼 포맷은 과제 원문 README/제공 파일에 맞춰 구현해야 한다.
> (일반적으로는 `닉네임,날짜,시간` 형태로 구성되며, 구현 시 파일 예시에 맞게 파싱한다.)

---

## ⌨️ 입력 요구사항

- 메뉴 선택: `1~4`, `Q`
- 닉네임: 등록된 크루 닉네임만 허용
- 날짜: `12월 N일` 형식 (예: `12월 14일`)
- 시간: `HH:MM` (24시간 표기)

---

## 🖨️ 출력 요구사항

- 초기 메뉴에서 “오늘 날짜”와 메뉴를 출력한다.
- 각 기능 수행 결과를 요구 형식에 맞게 출력한다.
- 에러 메시지는 반드시 `[ERROR]`로 시작한다.

---

## ❗ 예외 처리 요구사항

잘못된 입력이 들어오면 **에러 메시지를 출력**하고 프로그램을 **종료**한다.

에러 메시지 예시(대표):

- `[ERROR] 잘못된 형식을 입력하였습니다.`
- `[ERROR] 등록되지 않은 닉네임입니다.`
- `[ERROR] 12월 14일 토요일은 등교일이 아닙니다.`
- `[ERROR] 아직 수정할 수 없습니다.`
- `[ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.`
- `[ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해 주세요.`

## 🧑‍💻 프로그래밍 요구사항 (JavaScript)

- 언어: **JavaScript (Node.js)**
- 입출력: **콘솔 기반**
- 구현은 “작게 나누어” 작성한다.
  - 입력 검증 로직
  - 시간 판정 로직
  - 출석 집계 로직
  - 위험자 분류/정렬 로직
- 함수는 한 가지 책임만 가지도록 분리한다.
- 매직 넘버(예: 5분, 30분)는 상수로 관리한다.
